## USB Drive Setup Guide (After Downloading from GlowCadence.com)

1. Format a USB flash drive as **exFAT**, **FAT32**, or **ext4** (must **not** contain a `TeslaCam` folder).
2. Create a top-level folder named **`LightShow`** (exact capitalization).
3. Place your `.fseq` and `.wav` / `.mp3` files from **[glowcadence.com](https://glowcadence.com)** inside `LightShow/`.
4. Plug the USB drive into your vehicle's data USB port (glovebox USB port in most Teslas), open **Toybox → Light Show → Schedule Show**, and step outside!
